# Biblioteca en Java

- Se crea la interfaz `Catalogable`.
- Se crea la clase abstracta `Material`.
- Se crean las clases hijas `Libro` y `Revista`.
- Se utiliza `HashMap` para el catálogo de materiales.
- Se utiliza `ArrayList` para las listas de espera.
- Se utiliza `HashSet` para registrar las membresías.
- Se crea la clase `SistemaBiblioteca`.
- Se crea `Main` para probar el funcionamiento del sistema.
